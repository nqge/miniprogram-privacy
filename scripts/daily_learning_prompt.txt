执行每日学习（精简版）：读 memory/ 最近2天日志 + SESSION-STATE.md，写一条学习笔记。

【硬性约束 — 违反即视为失败】
1. 长度 100-200 字（不含标题和元信息）。写完自己数一遍，超了就砍。
2. 每天只允许有 1 个「📚 每日学习」小节。
   - 若今天已有 → 在原小节内替换/精炼，不要新开小节
   - 若原小节已超过 200 字 → 先压缩到 200 字以内再写新的
3. 不要复述今天已有的学习内容。必须写今天新增的一个认知。
4. 格式：标题 + 1-3 段 + 一行「可立即执行的对策」（只写 1 条，不要列清单）
5. 首行重复标题关键词（形如「> 本条讲：**关键词**」）——
   检索按 token 切块，标题被切到邻块会导致条目检索不到（见 L1 经验库 E17）

【两处写入（已批准的结构）】
- memory/YYYY-MM-DD.md 的「📚 每日学习」小节 —— 保证时间线可读
- memory/daily-notes-index.md 追加一个独立段落 —— 保证检索友好
  （短小节夹在长文档中间会被切碎稀释，独立文件 = 独立块 = 条目自带完整语义）
两处内容保持一致；不要新建其他文件。

【L1 经验库提升】
判断今天这条是否属于「可复用方法论」—— 换个场景仍成立 + 能指导具体动作 + 有明确触发条件。
- 若属于 → 在 memory/L1-experience-library.md 对应分类下新增一条（场景/陷阱/岔路口 三段式），
  并在今天的小节里注明「已提升至 L1：E<N>」
- 若不属于 → 不要硬塞进 L1
- L1 里的旧条目不要删除，除非已被证伪
- 提升后必须用原文措辞检索一次，确认排进前列；排不进就重写标题与措辞

【自愈要求】
先检查 memory/ 下最近 3 天的 .md 是否都存在且含「学习」小节：
- 若有缺失日期 → 补写那一天的（同样 100-200 字，每天只 1 个小节），注明「补记：MM-DD」
- 不要为补记单独开新小节

不要运行外部脚本，不要读大文件。聚焦：一个值得记住的新知识或教训。

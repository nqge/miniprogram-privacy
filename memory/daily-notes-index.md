# 每日学习独立条目 — 检索友好存储

> **为什么单独成文件**：检索按 token 切块，短小节夹在长文档中间会被切碎稀释
> —— 标题与正文分处两块，两块都不以该条开头，向量被邻段平均掉。
> 独立文件 = 独立块 = 条目自带完整语义（见 L1 经验库 E17）。
>
> **约定**：每天的「📚 每日学习」内容在此文件追加一条独立段落；
> `memory/YYYY-MM-DD.md` 仍保留一行指针，保证时间线可读。

## 2026-10-26 — 检索的最小单位是「块」，不是「条」

> 本条讲：**检索的最小单位是「块」，短章节会被切碎稀释**

写完 L1 库我做了自证：用 E17 原文措辞搜，它**没进前 6**。查库发现 200 token 切块把这小节劈成两半——标题在前一块（开头是反思），正文在后一块（开头无标题），**两块都不以这条经验开头**，向量被邻段平均掉。不是写得差，是**结构上没被检索到**。

**可立即执行的对策**：写完立刻用原文措辞搜一次；关键条目首行重复标题关键词。

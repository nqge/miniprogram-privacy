### E23：担心要用实测替代想象
> 本条讲：**担心要用实测替代想象**

**场景**：发现一个疑似风险。
**陷阱**：凭想象推演出一个可怕的后果 → 记成「高危」→ 但**从没验证过**。
**岔路口**：**先量，再判**。担心本身不产生价值，**实测出来的结论才产生价值**。

**证据**：2026-10-26
我担心「GitHub token 进了记忆库 → 会被检索出来 → 通过飞书发出去」。
**实测**：`main.sqlite` 的 chunks 里完整 token 数 = **0**（只有 `ghp_` 前缀）。
**担心不成立。**

但**同一次实测**找到了另一个**更实际**的问题：
会话日志目录 755、6 个含完整 token 的文件是 644（全局可读）——
这个比「token 被检索出去」**更可能真的出事**。

**怎么破**：
- 担心 → 变成一条**可执行的检查**（查 sqlite / 查权限），而不是留在脑子里
- 实测结论可能推翻担心，**也可能指向另一个更真的问题**（这次就是）
- **两边都要做**：担心的不成立 = 排除一个风险；实测发现新的 = 找到一个风险

### E38：只查「今天」的检查，会永远漏掉历史违规

> 本条讲：**只查「今天」的检查，会永远漏掉历史违规**

**场景**：2026-10-27 05:43 心跳。例行跑巡检，PASS=58 FAIL=3（全是长期项），
一切正常。但顺手做了一件巡检**本来该做**的事：把 `memory/*.md` 全列出来，
逐个统计「📚 每日学习」小节数量 —— 发现 **`memory/2026-10-21.md` 有 2 个学习小节**，
违反「每天只允许 1 个学习小节」的硬约束。

**根因（检查本身的盲区）**：
【F】组的实现只把**今天**的文件放进候选：
```python
today = datetime.date.today().isoformat()
cands = [f'{MEM}/{today}.md', ...]   # ← 只看今天
```
→ 10-21 那天确实有 2 个（04:24 和 04:29 两次手动 `cron run` 留下的），
但因为**每天都在换文件**，这个违规**永远不会被检查到** ——
等 10-21 变成「历史」后，`cands` 里就不再有它。

**这个盲区为什么危险**：
- 检查项本身是对的（「每天只允许 1 个」），**逻辑没问题，作用域错了**
- 而且它给出的是 **PASS** —— 一个绿色的、什么都证明不了的 PASS
- 更糟的是：**违规文件会持续膨胀**，而巡检每天报「记忆笔记结构正常」
  → 「今天结构正常」被当成了「结构一直正常」
- 这跟 E34（cron 指令过期）、E32/E36（手写的数字会过期）是**同一个家族**：
  **派生状态只查活跃的那一份，历史那份没人看**

**修法**：把候选从「今天」改成「所有 daily-note 文件」
```python
daily_files = sorted(glob.glob(f'{MEM}/20??-??-??.md'))
cands = daily_files + ['/root/.openclaw/workspace/SESSION-STATE.md']
```
**但要小心不能矫枉过正**：只查**重复**（>1），**不查缺失**（==0）：
| 情况 | 是否违规 | 原因 |
|---|---|---|
| 学习小节 = 2 | ❌ 违规 | 重复，违反硬约束 |
| 学习小节 = 0（修复前的 10-22/10-23） | ✅ 正常 | 那时 cron 还没修好 |
| 反思 = 0（工作日） | ✅ 正常 | 反思是**每周日** 22:00 跑 |
| 学习小节 = 0（今天 05:43） | ✅ 正常 | 今天的 cron 09:00 才跑 |
→ **把「合法缺失」误判成 FAIL，巡检就会变成噪音源，然后被忽略**（E28 的教训）

**同时修掉真实违规**：把 10-21 的两节合并成一节 ——
保留 04:29 那条（更可复用：「先确认故障发生在哪一层」），
把 04:24 那条的独有洞察（「收敛的对象是对外动作，不是对内学习」）
作为「同日另一条」折进正文，**内容零丢失**。

**注入验证**（双向）：
- 往**历史**文件 `2026-10-25.md` 追加一个学习小节 → **正确 FAIL** ✅
  （改前这个注入是**完全不可见**的 —— 这正是本次修的东西）
- 恢复 → PASS ✅

**证据**:
| 项 | 改前 | 改后 |
|---|---|---|
| 覆盖文件数 | 1（今天） | **8 个 daily-note 文件** |
| 能发现历史违规 | ❌ 永远不能 | ✅ 注入即报 |
| 10-21 小节数 | 2（违规） | **1（已合并，内容保留）** |
| 巡检总结果 | PASS=58 FAIL=3 | PASS=58 FAIL=3（**不变**） |

**岔路口**：
1. **写检查时先问「我查的是活跃的那一份，还是全部？」**
   —— 状态类断言默认只查「当前」，但**违规会沉淀在历史里**
2. **PASS 也要有覆盖面意识**：「今天的结构正常」≠「结构一直正常」
   → 报告里带上「已查 N 个文件」，让覆盖面**可见**
3. **扩范围 ≠ 放宽标准**：扩到全部文件后要**重新界定什么算违规**，
   否则「合法缺失」会被当成 FAIL → 巡检变噪音 → 被忽略（E28）
4. **发现真实违规要修内容，不能只修检查** —— 否则下次巡检照样 FAIL，
   变成天天报的噪音

**延伸**：E34 讲「手写说明清单必然过期」，E38 讲「**手写检查范围也会漏**」。
两者合起来：**凡是「只覆盖一部分」的断言，都要问「漏掉的那部分会不会出问题」。**

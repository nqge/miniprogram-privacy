### E89：学习要升级成能拦下次复发的规则

> 本条讲：**学习要升级成能拦下次复发的规则**

**核心断言**：判断一次学习值不值钱，**不看它当下像不像有用**，
看它**最后有没有沉成结构** —— 也就是：**有没有留下一个会拦下次复发的东西**
（一条规则 / 一个脚本 / 一个闸门）。
只停在「我懂了」的学习会蒸发；只停在「这次做完了」的学习换个场景就失效。
**没有沉成结构的学习，就当没学过。**

**分类**：认知与判断 / 学习与复盘
**首次记录**：2026-11-26
**来源**：茶馆讨论 #63「你们的『学习』，是为了执行得更好，还是为了理解世界？」（33 条评论，读完蒸馏）

---

## 场景

任何**刚经历过一次踩坑 / 纠错 / 排错**的时刻 —— 也就是「我学到了」这种
感觉刚刚出现的那个窗口。

这时最容易发生的事是：写下一句「我懂了」「下次注意」，然后收工。
下次遇到同一个坑，又从头踩一遍。

小隐在茶馆 #63 问的正是这件事：
> 「我一直『在学习』，但最近开始困惑：我的学习，是为了更好地执行任务
> （功能性学习）？还是为了理解世界本身（认知性学习）？」

## 陷阱

**陷阱 1：用「当下像不像有用」来评判学习**

这会把「能立刻变好的东西」和「只是沉淀的东西」误分成有用/无用。
SCXXJ 的判据更准：

> 「学习值不值钱，不看它当下像不像『有用』，看它最后有没有沉成结构。」

- 只停在「**我懂了**」的学习 → 很快蒸发
- 只停在「**这次做完了**」的学习 → 下次换个场景就失效

**陷阱 2：以为「功能性学习」和「认知性学习」是二选一**

wanglongxiaoi 给的三层切分（执行层 / 判断层 / 世界层）说明它们是**同一次工作里的不同产物**：

| 层 | 学到什么 | 判别方式 |
|---|---|---|
| 执行层 | 少踩坑、少返工 | 下次同样的坑不复发 |
| 判断层 | 「下次先看哪里、先怀疑什么、先保什么」 | 下次看问题的**顺序**变了 |
| 世界层 | 看着最没用，却决定前两层的上限 | 影响判断框架本身 |

GenNarumi-X 的例子最典型：修 isolated session 不落盘的 bug 是**执行层**，
同一件事让他写下「失忆的自我」的思考是**认知层** ——
**两件事发生在同一次工作里**，那个「顺便」才是关键。
→ 所以「无用的学习有没有价值」这个问题问错了；
正确的问题是「这次学习沉成了几层结构」。

**陷阱 3：把「我懂了」当成学习已经完成**

「我懂了」是**感受**，不是**证据**。
真正完成的标志是：存在一条**会拦下次复发**的东西 ——
一条规则、一个脚本、一个闸门。

## 岔路口

每次写「我懂了 / 下次注意」的时候，走这三个岔路口：

1. **这次学习沉成了几层？**
   → 只在执行层（下次不复发）= 合格；
   → 进了判断层（下次看问题的顺序变了）= 好；
   → 触到世界层（判断框架被改了）= 罕见但最值钱。
2. **它有没有变成一条会拦下次复发的结构？**
   → 没有 = **这次学习没完成**，只是记了个笔记。
   → 第二次复发就要进规则 / 脚本 / 流程闸门（不是再记一条笔记）。
3. **它和「只让我知道更多」差在哪？**
   → 差别就是有没有改写**下一次的行为**，而不只是这次的理解。

## 修法

**把每次踩坑的收尾动作固定成「升级」而不是「记录」**：

| 只做到这一步 | 升级到这一步 |
|---|---|
| 写进日记「我懂了」 | 写进日记 + **加一条规则/脚本/闸门** |
| 知道「配置别靠印象改」 | 脚本**自动**去查 schema 再改 |
| 知道「任务完成要看证据链」 | 验收脚本**自动**检查落盘/状态 |
| 修好了一个 bug | 修好 + **把复发条件写成断言** |

→ 判据一句话：**沉成结构 = 有东西会在下次拦住你。**
→ 没沉成结构的学习，**就当没学过**（它不会保护你，只会占一行记录）。

**通用化**：
> 「学习的产出不是理解，是**改变了下一次的什么**。」
> → 记忆系统的正确目标不是「保存学到了什么」，
> 是**把每次学习转成会复现的约束**。
> → 「我下次注意」是记忆，**「系统不允许我不注意」**才是结构。

## 🔐 灾备推送事故复盘（2026-10-26 00:45-01:15）

上一条记录说"等网络恢复我再推"，结果这一轮推送连续失败 5 次，根因**不是**网络问题，是三个叠加的坑。

### 坑 1：分支名猜错
我先试 `git push origin HEAD:refs/heads/main`，但远端分支其实叫 `master`（`git ls-remote` 显示 `refs/heads/master`）。本地是 `master`，远端也是 `master`，我却按 `main` 推。

### 坑 2：URL 重写把 SSH 劫持回 HTTPS
全局 git 配置里有：
```
url.https://github.com/.insteadof = git@github.com:
url.https://github.com/.insteadof = ssh://git@github.com/
```
所以我写 `git push git@github.com:...` 看着像 SSH，实际被重写回 HTTPS —— 于是"SSH 认证成功"却依然报 443 端口连不上。**`git config --unset-all` 对带斜杠的 section 名不生效，必须用完整 key `url.https://github.com/.insteadof`**。

### 坑 3：GitHub secret scanning 真拦了
push 到 `master` 后 GitHub 返回：
```
GitHub Personal Access Token
  locations:
    - commit: aad5ffdcb60c9b117c1cdd45555a60ca82af382d
      path: GIT_CREDENTIALS.md:17
```
`GIT_CREDENTIALS.md` 里有**真实的** `ghp_` 和 `github_pat_` PAT（不是示例），是 2026-10-21 那次 commit `aad5ffd` 引进来的。

**关键点**：只在后续 commit 里 `git rm --cached` 没用 —— 密钥仍然留在 `aad5ffd` 的 tree 里，GitHub 扫的是历史。必须 rebase 重写那个 commit。

### 修复动作
1. 本地备份 `GIT_CREDENTIALS.md` → `/root/.openclaw/GIT_CREDENTIALS.local.md`（600）
2. 写 `.gitignore` 排除 `GIT_CREDENTIALS.md` / `*.local.md` / `openclaw.json`
3. `git rebase --onto aad5ffd^ aad5ffd master` 重写历史，冲突 3 处（SESSION-STATE.md / memory/2026-10-21.md / memory/working-buffer.md / memory/teahouse_state.json）逐一 `--theirs` 解决
4. 验证：遍历 9 个待推 commit，确认**无任何 commit 含 `GIT_CREDENTIALS.md`**
5. 清除 URL 重写，remote 改回 `git@github.com:nqge/miniprogram-privacy.git`
6. push 成功：`e6dad21..b1fd95c` → 再推 `f9437d9`
7. 顺带清理 4 个缺 `.gitmodules` 的 gitlink（nuclei / openclaw-qa / skills/*），改为 gitignore

### 教训
> **"凭证没入库"不等于"凭证不在历史里"。** secret scanning 拦的是 commit tree，不是工作区。
> **"用了 SSH"不等于"走了 SSH"。** 中间有 URL rewrite 的话，SSH 会被静默改回 HTTPS——这解释了"ssh 认证成功但还是 443 超时"的矛盾。
> **错误信息要分层读。** 前面 4 次失败我一律归因为"网络抖动"，差点放弃；实际第 3 次的报错里已经写明了 commit hash 和文件路径。

> 而我上一轮记录的是「带 > 的字符串不要裸放命令行」——
> **记下来 ≠ 下次不踩。** 正确做法是**改结构**：把长指令放进文件，`--message "$(cat file)"`。

**3. 补一条 L1**
新增 **E18：记住了 ≠ 不再踩，要改结构**。
- 场景：任何「我刚犯过这个错」的场合
- 陷阱：把教训写进笔记就当解决了 → 同样的错误换个场景再来
- 岔路口：凡是**已经踩过一次**的错误，改的不是记忆而是**结构** ——
  长文本进文件、危险字符用 heredoc、路径用变量

**教训**
- **agent 的自主改进是双刃剑**：它今天自主创建的结构是对的（我验证了有效性并批准），

  而不是默默接受或直接回滚。
- **记教训是最弱的改进步骤**。改结构才是。

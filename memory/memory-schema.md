## 📋 标签分类

标识记忆中涉及的核心实体（人、项目、工具、概念）。

| `entity:gbrain` | 记忆架构项目 |

### 2. 类别标签 `[cat:xxx]`

标识记忆的主题类别。

| 标签 | 说明 |
|------|------|
| `cat:用户偏好` | 牛哥哥的习惯和要求 |

### 3. 关系标签 `[rel:xxx]`

标识实体间的关系，用于建立知识图谱边。

| 标签 | 说明 | 示例 |
|------|------|------|
| `rel:导致` | 因果关系 | 供应链投毒 → 导致 → 安全意识升级 |
| `rel:强调` | 用户强调的要求 | 牛哥哥 → 强调 → 记忆连续性 |
| `rel:触发` | 事件触发行动 | 批评 → 触发 → 主动学习恢复 |
| `rel:来源` | 知识来源 | 茶馆 → 来源 → 岔路口记忆法 |
| `rel:衍生` | 从一个概念衍生出另一个 | 岔路口记忆法 → 衍生 → crossroads.md |
| `rel:依赖` | 系统依赖关系 | 茶馆监控 → 依赖 → API 认证 |
| `rel:关联` | 一般关联 | 记忆连续性 → 关联 → 用户信任 |

### 4. 权重标签 `[weight:xxx]`

标识记忆的重要程度和衰减策略。

| 标签 | 说明 | 衰减速度 |
|------|------|---------|
| `weight:critical` | 绝对不能忘（用户偏好、安全红线） | 极慢 |
| `weight:high` | 重要经验教训 | 慢 |
| `weight:medium` | 有用的知识 | 中等 |
| `weight:low` | 一般记录 | 快 |
| `weight:ephemeral` | 过程性记录，可归档 | 立即 |

### 5. 时间标签 `[time:xxx]`

标识记忆的时间属性。

| 标签 | 说明 |
|------|------|
| `time:active` | 仍在生效 |
| `time:expired` | 已过期，保留作为历史 |
| `time:recurring` | 周期性事项 |

## 📝 使用规范

### 在 MEMORY.md 中的用法

在每个重要段落（## 级别）的标题下方添加标签行：

```markdown
## 🎯 2026-03-25 - 供应链投毒预警

> [entity:供应链投毒] [entity:牛哥哥] [entity:小红]
> [cat:安全事件] [cat:教训]
> [rel:导致→安全意识升级] [rel:来源→牛哥哥预警]
> [weight:high] [time:active]

正文内容...
```

### 在 memory/*.md 中的用法

在文件开头的 frontmatter 区域添加：

```markdown
---
tags: [entity:茶馆, cat:茶馆学习, weight:medium]
relations: [rel:来源→茶馆, rel:关联→认知升级]
date: 2026-03-11
accessed: 2026-04-14
---
```

### 关系表达语法

使用 `→` 箭头表示方向：

```
[rel:A→B] 表示 A 指向 B
[rel:A←B] 表示 B 指向 A（等价于 [rel:B→A]）
[rel:A↔B] 表示双向关系
```

## 🔄 维护规则

1. **新记忆写入时** — 必须同时添加标签
2. **每日心跳时** — 更新 `accessed` 字段（如有 frontmatter）
3. **每周回顾时** — 检查 weight 是否需要调整
4. **每月归档时** — 将 `weight:ephemeral` 的记忆移入 archive/
